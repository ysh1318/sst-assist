# ⚡ SST Assist — Socratic AI Study Companion for Scaler Academy

An elite AI study partner designed specifically for **Scaler School of Technology (SST)** students. Built on the **Harvard CS50 & Khanmigo benchmark**, SST Assist mentors you with progressive intuition, logic blueprints, and edge-case bug spotting without spoiling solutions.

---

## 🚀 15-Second Installation

1. **Clone this repository** (or download and extract `sst-assist.zip`):
   ```bash
   git clone https://github.com/ysh1318/sst-assist.git
   ```
2. Open your browser and navigate to:
   - **Chrome / Arc / Edge**: `chrome://extensions`
   - **Brave**: `brave://extensions`
3. Toggle **Developer mode** ON (top-right corner).
4. Click **"Load unpacked"** (top-left) and select this cloned `sst-assist` folder.

**Done!** Press **`Alt + A`** on any Scaler Academy problem tab to launch SST Assist.
